### 02. DocMind-VLM
**Dual-Stream Multimodal Document Intelligence**

A multimodal document question-answering system that combines native vision-language reasoning with OCR-based language-model processing.

- Qwen2.5-VL-based document understanding.
- Parallel visual and OCR-based processing.
- Cross-modal claim verification and evidence extraction.
- Causal failure analysis and explainability.
- Benchmarking and evaluation using DocVQA.

**Reported evaluation:** 85.5% exact match and 0.9057 ANLS on a balanced 200-item DocVQA validation subset.

**Tech Stack:** `Python` `PyTorch` `Qwen2.5-VL` `RapidOCR` `ONNX` `FastAPI` `Next.js`
